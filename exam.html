Hardware Definition: Physical hardware components that make up computers and other electronic devices. Main Components: CPU (Central Processing Unit): The computer's brain that executes instructions from software. RAM (Random Access Memory): Temporary memory used to store data and instructions being processed by the CPU. Motherboard: The main board that connects all hardware components. Storage: Devices used for permanent data storage, such as HDD (Hard Disk Drive) or SSD (Solid State Drive). GPU (Graphics Processing Unit): Component for processing graphics and visuals. Power Supply Unit (PSU): Provides electrical power to all computer components. Peripheral Devices: Additional devices like keyboard, mouse, monitor, printer. Function: Provides the physical infrastructure needed to run and operate software. Stores and processes data. Examples: Computer, laptop, smartphone, printer.
